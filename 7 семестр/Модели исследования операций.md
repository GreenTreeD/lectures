
# Лекция №2
## Транспортная задача
*Балансировка транспортной задачи* — это приведение суммы всех запасов поставщиков к сумме всех потребностей покупателей, чтобы сделать задачу закрытой и пригодной для решения.

**Графовая постановка задачи:**
$S_i, i = 1...m$ => 
$T_j, j = 1...n$ =>

![[Pasted image 20260908121324.png|335]]
Между каждым ребром стоит $c_{ij}$ -  стоимость перевозки сырья из $S_i$ в $T_j$. Это ребро означает, что перевозка возможно и что общая стоимость, включая все накладные расходы, известна.
 
**Постановка задачи в терминах линейного программирования:**
$S_i$ -> $T_j$ - магистраль со стоимостью $c_{ij}$. Поставим этой магистрали в соответствие переменную $x_{ij}$, которая обозначает объём перевозок. 
Для каждого источника запишем следующее равенство: $$S_i \cdot \sum_{j = 1}^n x_{ij} = A_i, i = 1\dots m$$
Таких уравнений будет столько, сколько источников, т.е. $m$.
Запишем ограничение для приёмников: (объём продукта, который везём из пункта i в пункт j)
$$T_j \cdot \sum_i^n x_{ij} =  B_j, j = 1\dots n$$Целевая функция:
$$Z=  \sum_{j=1}^n \sum_{i=1}^m c_{ij}x_{ij} \rightarrow \min$$
Количество переменных: $m\cdot n$
Количество ограничений: $m+n$
Из них $m+n-1$ являются линейно независимыми, поэтому решений бесконечно много.

*Базисный транспортный план* -  такое решение, у которого $m+n-1$ переменных отлично от нуля, а все остальные равны нулю.
*Опорный план* - ациклический базисный план. Он нужен, чтобы применять *метод потенциалов*(метод оптимизации).

**Матричная постановка:**
Задача может быть полностью задана и решена с помощью *транспортной матрицы*:
![[Pasted image 20260908121514.png|605]]
Нулевые перевозки не заносим в клеточки.
По столбцам приёмники(T), по строкам источники(S), B - потребление в пункте, А - запасы на производстве. x - объём перевозок(неизвестные), с - стоимость перевозок.

|          | Москва        | Питер          |       |
| -------- | ------------- | -------------- | ----- |
| Калуга   | $x_{11}$\500  | $x_{12}$\1000  | 10000 |
| Тольятти | $x_{21}$\9000 | $x_{22}$\12000 | 3000  |
| Елабуга  | $x_{31}$\8000 | $x_{32}$\1400  | 500   |
|          | 3300          | 1200           |       |
Запишем ограничения:
По строкам:
$S_1: (x_{11}+x_{12}) = 10000$

Целевая функция:
$x_{11}\cdot 500 + x_{12}\cdot 1000 + x_{21}\cdot 9000 + x_{22}\cdot 12000 + x_{31}\cdot 8000 + x_{32}\cdot 1400 \rightarrow min$

Но такая постановка задачи не очень реалистичная, рассмотрим, как внести другие ограничения.

Но не всегда стоит так делать, так как такую задачу будет невозможно решить методом потенциалов.

## Метод двойных предпочтений
Метод синтеза опорных планов. 
Просмотрим по строчкам таблицу и галочкой отмечаем клеточку с минимальной стоимостью в строке. Если таких несколько, отмечаем все.
Посматриваем по столбцам и отмечаем с минимальной стоимостью в столбце.
Формируем транспортный план по следующим правилам.
1. Если есть клетки с двумя галочками, то выбираем самую дешёвую из них и насыщаем по правилу минимума. Повторяем, пока не закончатся клетки с двумя отметками. 
2. Упорядочиваем клетки с 1 отметкой и насыщаем по правилу минимума.
3. Если таблица не пустая, то работаем с таблицей по принципу минимальной стоимости


## Метод потенциалов
Преобразует циклический опорный план, полученный одним из вышеперечисленных методов, в базисный план. 
1. С каждой строкой таблицы связываются вспомогательные переменные - потенциалы. Потенциал строк - $U_i$, потенциалы столбцов - $V_j$
	$u_i + c_{ij} = v_j$
	Надо посчитать потенциалы всех строк и столбцов. 
	Переменных будет $m+n$, а уравнений - $m+n-1$. 
	Берём потенциал первой строки, равный нулю.
	Расчитываем потенциалы всех остальных строк и столбцов.
	(Например, известен потенциал $u_p$ и есть стоимость $c_{pq}$, тогда $v_q = u_p + c_{pq}$)
2. Для всех нулевых/свободных магистралей транспортной таблицы расчитываются псевдостоимости $\tilde{c_{ij}} = v_j - u_i$ , пишем в нижний левый
3. Для каждой свободной магистрали подсчитывается $\Delta_{ij} = c_{ij} - \tilde{c_{ij}}$, пишем в верхний левый
4. Проверка плана: план является самым дешёвым, если все $\Delta_{ij} \geq 0$.
5. Среди всех свободных клеток с отрицательной $\Delta_{ij}$ выбираем самую большую по модулю $\Delta_{pq} = \min \Delta_{ij} < 0$. Будем называть "дельта-магистраль". Она сейчас свободная, но выгодная, надо сделать её магистралью
6. Ищем цикл, которые начинается в "дельта-клетке", проходит только по базисным клеткам,в каждой базисной клетке поворачивает на 90 градусов и заканчивается в "дельта-клетке". Такой цикл всегда существует и всегда единственный. 
7. В клетках найденного цикла расставляем "+" и "-" начиная с "+" в дельта-клетке. Во всех клетках цикла, имеющих "-", ищем клетку с минимальной перевозкой. Обозначим "$\gamma$" и будем называть гамма-клеткой

## Основные положения венгерского алгоритма
Венгерским алгоритмом нам надо добиться минимума следующей целевой функции 
$$C = \sum_{j}^{n}\sum_{i}^{n}c_{ij}x_{ij} \rightarrow \min$$
Пусть есть следующее назначение со следующей целевой функцией, где есть матрица $n\cdot n$, из каждой ячейки i-ой строки вычтем $P_i$ такое, что все элементы должны остаться положительными. Из каждого столбца матрицы стоимости вычтем такое $q_j$ такое, что все элементы должны остаться положительными. Была исходная задача с матрицей $C = \Vert c_{ij} \Vert_{n\cdot n}$, получили матрицу $C' = \Vert c'_{ij} \Vert_{n\cdot n}$. 
Докажем, что это эквивалентное преобразование, т.е. оптимальная точка будет одинаковой для обеих целевых функций.

Запишем целевую функцию для задачи редуцирования: $$C' = \sum_{j}^{n}\sum_{i}^{n}c'_{ij}x_{ij} = \sum_{j}^{n}\sum_{i}^{n} (c_{ij} - p_{i}-q_{j})x_{ij} = \sum_{j}^{n}\sum_{i}^{n}c_{ij}x_{ij}-\sum_{j}^{n}\sum_{i}^{n}p_i x_{ij} - \sum_{j}^{n}\sum_{i}^{n}q_j x_{ij} = (-\sum_{j=1}^{n}q_j\sum_i^{n}x_{ij} - \sum_{i=1}^{n}p_i\sum_i^{n}x_{ij}) + \sum_{j}^{n}\sum_{i}^{n}c_{ij}x_{ij}$$
По условию задачи о редуцировании суммы при $q_j$ и $p_i$ равны 1, соответственно целевые функции различаются на константу -> оптимумы функции достигаются в одной точке с разностью на константу.

Трансверсаль индуцированной функции будет состоять из нулевых элементов.

## Матричный венгерский алгоритм
Даёт решение меньше чем за n-1 итерацию.
![[Pasted image 20260929125557.png]]

Начинается с подготовительного этапа: редукция матрицы стоимости. По столбцам слева направо, по строкам сверху вниз. Такая редукция гарантирует существование хотя бы одного нуля в каждом столбце и каждой строке.
Расстановка независимых нулей. Ноль называется независимым, если он единственный и в строке, и в столбце. Множество всех независимых нулей это частичная трансверсаль. Независимые нули будем отмечать как 0*. Как расставлять нули: рассматриваем матрицу слева направо сверху вниз. Если нашли независимый ноль, помечаем его \*. (Это важно для проверки)
Условие остановки: каждый столбец, имеющий независимый ноль, помечается сверху "+", если число независимых нулей равно n, то закончили, если меньше, то переходим к $A_1$: поиск зависимых нулей.
Если в строке есть один ещё 0*, то такой ноль помечаем как 0', такой ноль *зависимый*. Ищем первый слева столбец без отметки "+". Ищем там первый ноль, который не получил отметки.
![[Pasted image 20260929130925.png|300]]
Ставим плюсик на эту строку, отмечаем свободный 0 как зависимый и ставим номер по порядку у плюсика и у нуля. Тут ставим 1. Снимем пометку со столбца с ноликом(квадратик сверху плюса), чтобы он не был дважды под плюсиком и ставим пометку номера. 
Ищем непомеченный нолик в столбце с ноликом со звёздочкой, делаем тоже самое.
Когда заканчивается эта операция: когда на очередном шаге операции найден зависимый нолик единственный в строке, тогда выполняется переход к операции $A_2$, ЛИБО все нули таблицы находятся в помеченных линиях(строках или столбцах), тогда переходим к $A_3$. 
*Запрещается существования 2 и более зависимых нулей в одной строке.*

$А_2$: поиск аугментальной цепи, такая цепь из 0' и 0*, где можно увеличить число \*.
$0',0*,0'...0*,0'$, меняем статусы ноликов между собой: $0* \rightarrow 0', \quad 0' \rightarrow 0*$, потом стираем все отметки кроме \*, переходим в $A_0$.

$A_3$: дополнительная редукция матрицы стоимости. Переходим к ней, если все нолики находятся в отмеченных линиях. Находим мин элемент среди неотмеченных клеток и называем его h. Этот h вычитаем из всех клеток неотмеченных строк, прибавляем ко всем клеткам отмеченных столбцов.
Переходим к $A_1$

## Графовый венгерский алгоритм
Состоит из 3 подготовительных операций, которые делаются 1 раз, и из 4 основных операций.
Подготовительные:
1. Задача о назначениях задана полным двудольным взвешенным графом. Будем считать, что вершины нижней доли - исполнители $x_1 \dots x_n$, верхние - работы $y_1 ... y_n$, они все соединены рёбрами, вес ребра - стоимость назначения работника на работу. Такой граф можно представить в виде матрицы смежности долей.

|       | $y_1$ | $y_2$ | $y_3$ | $y_4$ |
| ----- | ----- | ----- | ----- | ----- |
| $x_1$ | 5     | 12    | 8     | 6     |
| $x_2$ | 10    | 7     | 9     | 9     |
| $x_3$ | 7     | 11    | 3     | 7     |
| $x_4$ | 3     | 2     | 12    | 6     |
	Так же производим редукцию матрицы стоимостей по столбцам и по строкам.
	После редукции получаем:

|       | $y_1$ | $y_2$ | $y_3$ | $y_4$ |
| ----- | ----- | ----- | ----- | ----- |
| $x_1$ | 2     | 10    | 5     | 0     |
| $x_2$ | 4     | 2     | 3     | 0     |
| $x_3$ | 4     | 9     | 0     | 1     |
| $x_4$ | 0     | 0     | 9     | 0     |
2. Поиск максимального количества паросочетаний в двудольном графе, состоящего из нулевых рёбер. Я хз как, но делаем тоже самое, как в матричном алгоритме с нулями.
	Мощность тут равна 3.

|       | $y_1$ | $y_2$ | $y_3$ | $y_4$ |
| ----- | ----- | ----- | ----- | ----- |
| $x_1$ | 2     | 10    | 5     | 0*    |
| $x_2$ | 4     | 2     | 3     | 0     |
| $x_3$ | 4     | 9     | 0*    | 1     |
| $x_4$ | 0*    | 0     | 9     | 0     |

3. Превращаем граф из этих паросочетаний в ориентированный граф. Все выделенные рёбра по направлению ориентируем вниз, а все невыделенные - снизу вверх.
	Нолики соответствующие выбранным помечаем -, а невыбранные - +

|       | $y_1$ | $y_2$ | $y_3$ | $y_4$ |
| ----- | ----- | ----- | ----- | ----- |
| $x_1$ | 2     | 10    | 5     | -0*   |
| $x_2$ | 4     | 2     | 3     | +0    |
| $x_3$ | 4     | 9     | -0*   | 1     |
| $x_4$ | -0*   | +0    | 9     | +0    |
	Вершины, к которым подходит выделенная дуга - насыщенные, вершины, к которым не подходит - не насыщенные. (которые соединяет выбранная дуга, и низ, и верх)
	Цель - увеличить мощность паросочетаний до кол-ва работников/работ.

5. Поиск аугментальной цепи
	Цепь начинается с невыбранной дуги, там чередуются невыбранные и выбранные дуги, и заканчивается невыбранной дугой.
