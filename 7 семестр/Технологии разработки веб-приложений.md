### XML - eXtensible Markup Language (1998)
- Расширяемый язык разметки
- Предназначение: формирование __машиночитаемых__ технических и юридически значимых документов
- Способы валидации документа:
	- Document Type Definition (DTD)
	- XML Schema Definition (XSD)
- Имеется возможность визуализации XML-документа с применением XSL-стилей (XSLT-преобразование документа в HTML)
``` xml
<?xml version="1.0" encoding="UTF-8"?>
<loremIpsum>
</loremIpsum>
```

### HTML - HyperText Markup Language (1991)
- Создан Тимоти Бернерсом-Ли (CERN) на базе SGML
- Ключевой добавленный тэг - `<a href="link.to/resource">link</a>`
- Первый официальный стандарт - HTML 2.0 (RFC 1866)
- *Отсутствие строгой валидации документа*
- Современность: HTML5/HTML Live Standard + интегрирование подмножества элементов (MathML, SVG)
``` html
<!DOCTYPE html> 
<html lang="en"> 
	<head> 
		<meta charset="utf-8"> 
		<title>title</title> 
		<link rel="stylesheet" href="style.css"> 
		<script src="script.js"></script> 
	</head> 
	<body> 
		<!-- page content --> 
	</body>
</html>
```

## Разновидности HTML-тэгов
- Метаданные документа (html, head, base, title, ..)  
- Секционные элементы (body, header, footer, nav, ...)  
- Группировка содержимого (main, div, p, ul, ol, ...)  
- Табличные данные (table и связанные с ним)  
- Интерактивные элементы (details, summary, dialog)  
- Скрипты (script/noscript, canvas, template)  
- Встроенное содержимое (img, picture, object, audio, video, ...)  
- Семантика текста (а + теги для стилизации и семантического выделения текста)  
- Правки в тексте (del, ins)  
- Формы (form + связанные с формами элементы, управляющие элементы input, button и прочие) 
- Элементы из внешних пространств имён (MathML, SVG)

## Семантическая вёрстка
Основная вёрстка: упор на смысловое предназначение каждого блока и логическую структуру документа.

Важность семантики:
 - Доступность сайта (в первую очередь для скринридеров)
 - Расположение сайта в поисковой выдаче
 - Поддержка со стороны стандарта HTML
